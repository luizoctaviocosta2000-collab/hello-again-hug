# Imobfy — Product Direction

## North star
Transform the existing real-estate workspace into a focused operating system for brokers and captadores. The product should feel premium, calm, fast and financially useful rather than like a generic admin template.

## Core flow
Captação → Imóvel → Proprietário → Cliente → Negócio → Visita/Agenda → Proposta → Fechamento → Comissão → VGV.

## Product principles
- Preserve existing Supabase/auth/business logic.
- Avoid decorative UI that does not improve a decision or action.
- Every major page needs one obvious primary action.
- Financial values use strong hierarchy and consistent formatting.
- Lists prioritize search, filters, status and next action.
- Empty states should explain what to do next.
- Mobile must remain usable for field work.

## Financial rules
Keep the existing commission rules. In particular, the configured 6% commission calculation must apply the existing 9% tax deduction and preserve the configured 20%/10% participation rules rather than inventing new percentages.

## Navigation model
Dashboard / Imóveis / Clientes / Negócios / Agenda / Comissões / Meu VGV / Configurações.

## Visual direction
Editorial premium real-estate aesthetic: warm off-white surfaces, charcoal navigation, restrained champagne/gold accents, generous spacing, compact typography, subtle depth, strong data hierarchy.
